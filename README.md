# flames-hub-relay

Мост между Telegram-ботом и хабом Flames. Хаб живёт в Яндекс.Облаке, откуда Telegram недоступен,
поэтому все запросы к Telegram делает этот мост на GitHub Actions.

- **Вебхук.** Telegram сам присылает сообщения бота в хаб: текст и кнопки обрабатываются сразу, ответ
  уходит в ответе на вебхук.
- **По событию.** Когда хабу есть что отправить в Telegram или нужно докачать фото/файл, хаб будит этот
  workflow (`workflow_dispatch`), и мост отрабатывает за ~30 секунд.
- **Опрос.** Если вебхук не доходит, мост сам снимает его и забирает сообщения через `getUpdates`, как раньше.
  Расписание — только запасной вариант.

Секреты репозитория: `TG_TOKEN` (токен бота), `HUB_URL` (адрес функции хаба), `RELAY_KEY` (ключ пересылки из хаба).
Хабу нужен токен GitHub с правом Actions: write на этот репозиторий — его вводят на Маке при активации функции.
